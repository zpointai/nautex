# Bundled fonts

Retrieved 12 September 2026 from the official repositories below. Files are bundled unchanged. Their respective licence texts are included in this directory.

- DM Sans regular and italic: https://github.com/google/fonts/tree/main/ofl/dmsans — SIL Open Font License 1.1.
- JetBrains Mono: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono — SIL Open Font License 1.1.
- Material Symbols Outlined variable font: https://github.com/google/material-design-icons/tree/master/variablefont — Apache License 2.0.

The desktop and backend use these local assets without requesting hosted font stylesheets.
